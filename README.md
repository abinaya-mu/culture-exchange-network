# Culture Exchange Network

A web application that helps users find language partners based on their native and learning languages.

## Features

- Create and save user profiles
- Match users based on language preferences
- View language partner profiles
- Open a demo chat and send messages
- Store user profiles and messages in MySQL

## Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MySQL
- **API:** REST APIs

## Setup Instructions

1. Install Node.js and MySQL.
2. Download or clone this repository.
3. Open the project folder in a terminal.
4. Install dependencies:

   `npm install`

5. Create a MySQL database named `culture_exchange`.
6. Create the required `users` and `messages` tables.
7. Create a local `.env` file with your database connection details.
8. Start the application:

   `node server.js`

9. Open `http://localhost:3000` in your browser.

## Note

This is a learning and portfolio project. The demo chat is not a production-ready private messaging system.
